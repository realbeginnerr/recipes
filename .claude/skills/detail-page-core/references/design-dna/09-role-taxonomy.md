# 09. 역할 택소노미

상세페이지의 모든 요소는 **역할**을 갖는다. 이 문서는 그 역할의 사전이고, 조형·타이포·색은 역할에서 따라 나온다.

## §0 왜 택소노미인가

빌더가 만든 페이지에서 반복되는 결함은 조형이 부족해서가 아니라 **조형은 있는데 역할 등급이 없어서** 생긴다. 배지는 만들었지만 강조/보조 티어가 없고, 비교표는 만들었지만 진영색과 각주색을 가르는 규칙이 없고, 마커는 만들었지만 붙어야 할 위치 규칙이 없다.

그래서 이 문서의 순서는 **사전이 먼저, 카탈로그가 나중**이다. §1~§5는 만든 것이 맞는지 재는 **자**이고, §6은 무엇을 만들지 고르는 **메뉴판**이다. 자 없이 메뉴판만 늘리면 결함이 늘어난다.

판정의 대원칙 하나: **역할은 이름이 아니라 위치·크기·색의 상대 관계로 판정한다.** 노드 이름은 원고가 바뀌면 거짓말이 되지만 관계는 남는다.

## §2 크기 사다리 — 6단 상대 등급

**본문(R06)을 1.0으로 놓고 배율로 정의한다.** 절대 px은 브랜드 프로파일의 몫이다.

| 등급 | 배율 | 담는 역할 | 왜 |
|---|---|---|---|
| **G1 초대형** | **브랜드 프로파일 값 슬롯**<br>(실측 근거: 본문의 4~7배) | 브랜드명, 비명(悲鳴)형 소구 | 존재 이유는 히어로의 비명 하나. **빈도 제한(페이지 1~2회)만 규범이고 배율은 브랜드가 정한다** — 절제된 브랜드는 G1을 아예 쓰지 않는 선택도 유효하다 |
| **G2 섹션 타이틀** | 본문의 **2~3배** | R01 | 스크롤 중 "여기서 화제가 바뀐다"를 크기만으로 알리는 유일한 신호 |
| **G3 소구·부제** | 본문의 **1.5~2배** | R02, R03 | 본문과 섞이지 않으면서 타이틀을 침범하지 않는 폭 |
| **G4 블록 제목** | 본문의 **1.2~1.5배** | R05, R09, R20 | 블록 안에서만 최상위. 섹션 타이틀과 경쟁하면 안 된다 |
| **G5 본문** | **1.0 (기준)** | R06 | 나머지 등급이 전부 이 값에 매달린다 |
| **G6 캡션·각주** | 본문의 **0.6~0.85배** | R07, R08, R13, R14 | 읽히되 멈추게 하지 않는 크기 |

**규칙 2-1. 등급 간 배율을 좁히지 않는다.** G2가 본문의 1.5배 이하로 내려오면 섹션 타이틀과 부제, 부제와 본문이 서로 구분되지 않는다.
*위반 시 증상 — 스크롤해도 화제 전환이 느껴지지 않고 페이지가 한 덩어리로 읽힌다.*

**규칙 2-2. 색 하강과 크기 하강은 한 쌍이다.** G6로 내려보낸 역할은 색도 회색으로 내린다. 크기만 줄이고 본문색을 유지하면 각주가 본문과 같은 무게로 읽혀 눈이 멈춘다.
*위반 시 증상 — 사양 부기나 면책 문구에서 독자의 시선이 걸린다.*

**규칙 2-3. 같은 사실이 두 역할로 두 번 등장하면 등급이 역전되지 않게 한다.** 히어로 배지(G4)에 쓴 문구를 하단에서 각주(G6)로 반복할 때, 뒤에 나오는 쪽이 더 커서는 안 된다.

## §3 서체 2갈래 원칙

정본 4파일 전부 예외 없이 두 갈래만 쓴다.

| 갈래 | 담는 역할 | 왜 |
|---|---|---|
| **디스플레이** | R01 섹션 타이틀, R02 부제, R03 소구, R11 **넘버**, 브랜드명 | 크기만으로는 "선언"과 "설명"이 갈리지 않는다. 서체가 두 번째 신호다 |
| **본문** | 나머지 전부 — 본문·캡션·각주·표·리뷰·라벨 | 읽는 글은 한 서체로 통일해야 눈이 쉰다 |

**규칙 3-1. 넘버는 디스플레이 갈래다.** 순서 표식은 읽는 글이 아니라 보는 표식이므로 본문 서체에서 떼어낸다. 본문과 다른 서체를 쓰면 크기를 키우지 않고도 표식으로 읽힌다.
*정답 예시 — 넘버에 모노스페이스 계열을 배정(크몽 `799:777`, `851:776`).*

**규칙 3-2. 손글씨·필기체는 긴박·희소 전용이다.** "출시!", "○명 한정"처럼 시간·수량이 걸린 자리에만 쓰고, 다른 역할에는 쓰지 않는다. 배정처를 좁게 유지해야 등장할 때 신호가 된다.
*정답 예시 — 클라이언트 B `670:3198`(출시!), `960:277`(30명 한정) 두 곳뿐.*

**행간**: 소구·타이틀은 **110~120%**(뭉쳐서 한 덩어리로 보이게), 본문은 **140~160%**, 리뷰 본문만 **170~175%**(남의 말이라 호흡이 길어야 한다).

## §4 색 배타성 규칙

색은 역할에 **배타적으로** 배정된다. 한 색이 두 역할을 겸하면 독자가 그 색의 뜻을 학습하지 못한다.

**규칙 4-1. 회색은 각주·출처·부가정보(R07·R08·R13·R14)에 배타 배정된다.**
따라서 **비교의 진영색으로 쓸 수 없다.** 대조군을 회색으로 칠하면 독자는 그것을 "대비되는 다른 선택지"가 아니라 "덜 중요해서 흐려놓은 정보"로 읽는다.
*위반 시 증상 — 비교표가 비교로 읽히지 않고 편들기로 읽혀 설득력이 떨어진다.*

**규칙 4-2. 비교의 두 진영은 면·테두리·헤더 색으로만 구분하고, 본문 텍스트의 색과 굵기는 양쪽을 동일하게 둔다.**
세로 스크롤에서는 두 진영이 한 화면에 안 들어오는 순간이 오는데, 그때 짝을 보증하는 것은 위치가 아니라 색이다. 진영색은 **증거 이미지의 테두리와 그 이미지의 캡션칩에 동시에** 걸어야 짝이 끊기지 않는다.
*정답 예시 — 클라이언트 B `1203:352`: A안 이미지 테두리와 A안 캡션칩(`1204:431`↔`1204:408`), B안도 동일 방식(`1205:437`↔`1204:411`). 양쪽 본문색은 같다.*

**규칙 4-3. 브랜드색 면 위 글씨는 문장의 성격으로 정한다.** 선언·구호는 **반전(흰색)**, 조곤조곤한 설명은 **어두운 동계열**.
같은 면에 두 성격이 섞이면 어느 쪽도 강조되지 않는다.
*정답 예시 — 클라이언트 B `936:1534`(선언, 반전) / `959:439`(설명, 어두운 동계열).*

## §5 조형 매핑 — 역할이 조형을 정한다

| 역할 | 조형 | 왜 |
|---|---|---|
| R16 증거 이미지 | **라운드 + 테두리 + 그림자 3종 세트** | 세 개가 함께 붙어야 "제출된 자료"로 읽힌다. 하나라도 빠지면 삽화가 된다 |
| R17 장식 이미지 | 무장식(라운드·테두리·그림자 없음) | 분위기 컷이 증거 옷을 입으면 진짜 증거의 신뢰가 희석된다 |
| R09 라벨·칩 | pill 또는 작은 라운드. **채움 = 강조 / 아웃라인 = 보조** | 같은 행 안에서도 티어를 나눠야 무엇이 핵심인지 읽힌다 |
| R07 캡션칩 | 흰 채움 + **진영색 테두리** + 작은 라운드 | 캡션이 어느 진영의 것인지 색으로 보증한다(§4-2) |
| R10 마커 | 채움 + 반전 글씨 + 작은 라운드 | 마커는 **면**이지 굵은 글자가 아니다. 굵기만으로는 결론으로 승격되지 않는다 |
| 카드 | 흰/크림 채움 + 라운드 + 그림자 또는 가는 테두리 | 정보를 담는 그릇. 내용 없는 배경 데코 카드는 브랜드색을 쓰지 않고 회색으로 내린다 |
| 표 | **카드 하나 + 내부 가는 분할선.** 셀마다 박스를 만들지 않는다 | 셀을 박스로 만들면 선이 두 겹이 되어 표가 무거워진다 |
| R18 배경면 | 섹션 폭 **이상**으로 살짝 넘겨 깖 | 렌더링·내보내기에서 가장자리에 흰 실선이 남는 것을 막는다 |
| 큰 배너 | 폭 고정. 라운드는 pill을 버리고 중간값 | pill은 작을 때만 성립한다. 커지면 알약이 아니라 캡슐로 보인다 |

| # | 유형 | 구성 | 조형 |

## §7 네이밍 표준

노드명이 역할을 말하면 분류가 자동으로 되고, 이름이 원고를 말하면 원고가 바뀌는 순간 거짓말이 된다.

```
섹션    S{번호}_{블록유형}[_{변형}]     예) S03_증거논문, S07_후기, S11_스펙표
반복군  {블록유형}_그룹                 예) 근거카드_그룹, 리뷰카드_그룹
반복항  {블록유형}_{식별}               예) 근거카드_JMB2024, 활용_얼려서
요소    {역할}[_{내용요약}]             예) 마커_86퍼센트회복, 캡션_리뷰건수, 각주_기준치
구조    {구조역할}                      예) 상단텍스트존, 배경이미지존, 라벨셀, 값셀,
                                            출처행, 텍스트컬럼, 구분선, 불릿_래퍼
컴포넌트 {역할}_{티어}                   예) 배지_강조, 배지_보조, 칩_나열
자산    자산_{용도} (빌더용 — 페이지 노출 금지)
```

**규칙 7-1. 역할 접두는 §1 사전의 어휘만 쓴다.** 사전에 없는 역할이 필요하면 사전을 먼저 고친다. 이름과 사전이 어긋나면 판정 기준이 둘이 된다.

**규칙 7-2. 내용을 담은 텍스트 노드에 익명·원고 이름을 두지 않는다.** 이름은 그 자리의 **역할**을 적는다. 원고를 이름에 넣으면 원고 교체 시 이름만 옛것으로 남아 다음 빌더를 오도한다. (순수 구조 래퍼의 익명 이름은 우선순위가 낮다.)

**규칙 7-3. 컴포넌트 이름에 조형어(pill·박스·라운드·아웃라인)를 단독으로 쓰지 않는다.** 반드시 역할 + 티어. **조형은 이름이 아니라 결과다.**
*위반 시 증상 — 같은 컴포넌트가 서로 다른 역할에 재사용되면서 티어가 나뉘지 않아, 핵심 배지와 단순 나열칩이 같은 무게로 읽힌다.*

**필수 표기 3종**
| 표기 | 붙이는 곳 | 왜 |
|---|---|---|
| `_placeholder` | 실물로 교체될 이미지·텍스트 자리 | 빌더가 임시물을 최종물로 착각하는 것을 막는다 |
| `[GIF교체대상]` | 정지컷으로 대체된 모션 자리 | 교체 대상을 놓치는 사고를 이름 하나로 막는다 |
| `(빌더용 — 페이지 노출 금지)` | 원본 자산 보관 프레임 | 자산을 페이지에 잘못 끌어 쓰는 것을 막는다 |

## 이관 후보

**SKILL.md 하드게이트 추가 후보**
- 증거 이미지(R16)는 라운드·테두리·그림자 3종 세트가 모두 있어야 통과. 하나라도 빠지면 장식 이미지(R17)로 판정하고 증거 자리 배치를 반려.
- 회색 계열은 R07·R08·R13·R14에만 허용. 비교 블록(B11~B13)의 진영 텍스트에 회색이 검출되면 반려(§4-1).
- 각주 등급(G6) 역할에 본문 등급(G5) 이상의 크기가 검출되면 반려. 색 하강과 크기 하강을 한 쌍으로 검사(§2-2).
- B10·B14·B23·B26·B31 등 ▶ 표시 블록은 자식 순서를 검사. 마커(R10)가 증거물의 직후 형제가 아니면 반려(§6).
- 배지·칩 컴포넌트가 한 페이지에서 3개 이상 쓰이면서 티어(채움/아웃라인)가 하나뿐이면 경고(§5, R09).

**orchestration / build-recipes 반영분**
- 컴포넌트 생성 시 이름은 `{역할}_{티어}` 형식으로 강제하고, 조형어 단독 이름은 생성 단계에서 거부(§7-3).
- 섹션 프레임 생성 시 `S{번호}_{블록유형}` 접두를 자동 부여하고, 블록유형은 §6 카탈로그의 B코드에서만 선택하도록 목록 제한.
- 빌더 지시서 템플릿에 §1 사전 링크와 해당 블록의 ▶ 순서를 자동 인용(지시서에 순서가 빠지면 불량 지시서).
