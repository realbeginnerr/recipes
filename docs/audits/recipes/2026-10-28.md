| 화면·기능 | 분석 내용 | 주요 구현 |

## B. 진단 요약

단위는 아래 ID별 점검 항목이다. 여러 현상을 같은 원인으로 묶었으므로 화면 수나 테스트 수와 다르다. ‘적절함’은 코드와 제한된 테스트에서 확인한 범위이며 운영 동작 보증이 아니다.

문제 18건: P0 2건, P1 10건, P2 6건. P0는 데이터 손실 경로가 있는 항목이다. 실제 운영 피해 발생이나 빈도는 측정하지 않았다. 정상·확인 필요·해당 없음에는 개선 우선순위를 부여하지 않았다.

Nielsen 기준은 H1 상태 가시성, H2 현실과 일치, H3 사용자 통제, H4 일관성, H5 오류 예방, H6 기억 부담 감소, H7 효율성, H8 간결한 표현, H9 오류 이해·복구, H10 도움말로 표기한다. 문제별 관련 기준을 연결하되 모든 기준에서 반드시 결함을 만들지는 않았다. H8·H10을 포함한 최종 사용성 평가는 실제 화면·과제 테스트가 필요하다.
