# 레시피 목록·등록·수정 간격 점검

- 기준: `design-system.md` 2장, `design-system-reference.md`의 프로젝트 설정과 승인된 예외.
- 공식 참조: [Carbon Spacing](https://carbondesignsystem.com/elements/spacing/overview/).
- 검증 범위: 현재 작업 트리의 JSX, CSS 선언, 선택자 우선순위, 조건부 렌더링. 실제 Chrome의 계산된 스타일·스크린샷·모바일 실측은 미확인이다. 브라우저 연결 호스트가 사용 불가로 반환되었다.
- 최초 점검에서는 UI 코드를 수정하지 않았다. 이후 사용자가 아래 수정 계획을 승인하여 소스에 반영했다. 기존 작업 트리 변경은 유지했다.

## 판단 기준

Carbon의 간격 척도와 관계·계층 원칙을 함께 적용한다. 척도 밖의 값이 무조건 금지되는 것은 아니지만, 프로젝트의 명시적 설정·승인된 예외가 없는 임의 값은 정리 대상이다. 버튼·인풋의 내부 패딩은 해당 컴포넌트 규격도 확인해야 하므로 일반 레이아웃 간격만으로 판정하지 않는다. 치수·테두리·텍스트 행간·아이콘 크기는 요소 간 간격과 구분한다.

## 수치 일치만으로 완료할 수 없는 부분

- 사진 편집기는 한 사진 안의 URL·버튼·미리보기 사이와 다음 사진 그룹 사이 모두 작은 간격을 사용한다. 여러 장일 때 그룹 구분이 충분한지 실제 화면을 확인해야 한다. 이는 소스 구조에서 발견한 검토 항목이며 시각적 문제 확정은 아니다.
- 상단 본문 padding 40px과 도구 영역 padding 30px은 안팎으로 누적된다. 각 수치를 기준값으로 바꾸는 것 외에 영역의 역할과 전체 밀도를 확인해야 한다.
- JSX의 Tailwind 유틸리티와 전역 CSS가 동시에 있는 경우 유틸리티 숫자만으로 판정하지 않는다. 예를 들어 재료 검색 버튼의 `py-[0.65rem]`은 전역 버튼 padding에 덮일 수 있어 최종 계산값 확인 전 확정 항목에 넣지 않았다.

## 현재 기준과 일치하는 부분

- 본문 좌우 gutter: 모바일 16px·태블릿 24px·데스크톱 32px.
- 목록 도구 모음: padding 16px, 요소 간 gap 12px, 필터 간 gap 8px.
- 목록 본문 위 40px·아래 96px, 결과 수 안내와 카드 사이 24px, 더 보기 위 48px.
- 이름 필드 사이 16px, 레이블과 이름 입력 사이 4px, 날짜 입력 행 사이 8px, 조리 단계 목록 사이 16px·단계 내부 8px.
- 재료 추가 버튼 사이 8px, 저장·취소 버튼 사이 8px.

## 프로젝트 명세상 별도 규격

- 표 기본 셀 padding 10px 14px은 프로젝트 명세 4장의 사이트 전용 설정이다. 일반 간격 척도와 다르다는 이유만으로 변경하지 않는다.
- 연한 텍스트, 영양 상태의 색상 표현, 삭제 아이콘, 특정 새 탭 안내 생략은 승인된 표시 예외다. 이번 간격 점검에서 변경하지 않는다.
- 버튼·인풋 내부 padding은 컴포넌트 규격 및 프로젝트 설정과 별도로 대조한다. 이번 보고서는 모든 내부 패딩의 공식 규격 일치를 보장하지 않는다.

## 다음 검증

실제 브라우저에서 목록·등록·수정을 데스크톱과 모바일 너비로 확인하고, 최종 계산된 간격·긴 레이블·여러 사진·추가된 날짜·표 다음 메모의 간격을 대조한다. UI 수정 후에는 같은 공통 폼을 사용하는 등록·수정을 함께 검증한다.

## 승인 후 소스 적용

- 목록 카드 가로 간격: 모바일·태블릿 16px, 1024px 이상 24px. 세로 24px 유지.
- 목록 카드 사진 아래와 하단: 768px 이상 16px, 모바일 12px 유지. 조리시간 위 8px, 별점 사이 2px.
- 등록·수정 상단 도구 영역과 탭의 위아래 여백: 32px. 400px 이하 수정 탭 좌우 여백: 12px.
- 공통 폼에서 메모·차림 등 레이블과 입력 사이 8px, 표 다음 메모·조리 단계 및 독립 콘텐츠 사이 24px, 요리 그룹 순서 영역 위아래 24px.
- 재료 추가 버튼 영역의 아래 margin을 제거하여 다음 메모의 위 padding 24px 한 곳에서 간격 관리.
- 공통 폼의 상품 설명 영역: 내부 padding 24px, 필드 묶음 사이 16px, 묶음 안 8px. 다른 상품 편집 화면의 공용 스타일은 변경하지 않음.
- 사진 편집기: 사진별 묶음 안 8px, 사진 묶음 사이 24px. 구조로 그룹을 구분하며 여러 사진을 등록해도 동일하게 적용.
- 표 셀의 사이트 전용 padding 10px 14px 및 승인된 표시 예외 유지.
- 소스·CSS 우선순위를 대조했으며 실제 브라우저에서의 최종 시각 확인은 위의 검증 범위대로 미완료다.
- 적용 후 `npm run test:regressions`: 18개 파일·91개 테스트 통과. `npm run build`: 타입 검사와 Vite 빌드 성공. 운영 데이터 변경·배포는 수행하지 않았다.
