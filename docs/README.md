## 앞으로의 저장 규칙

- 메뉴별 UX audit는 `docs/audits/<메뉴 영문명>/YYYY-MM-DD.md`에 저장한다. 재진단은 새 날짜의 보고서를 만들고 이전 보고서를 보존한다.
- 새 보고서를 작성하면 이 색인에 링크·범위·상태를 추가한다. 이 규칙은 향후 이 저장소에서 메뉴별 audit를 수행할 때 적용한다.
- 보고서는 요청 기준의 A~E 형식, 코드 근거, 문서 정책과 구현의 차이, 검증 방법과 한계, 우선순위, 사용자 승인 상태를 포함한다.
- 최초 진단은 검토 대기다. 사용자가 승인한 정책은 PRD에서 관리하고 보고서에는 승인 여부와 해당 위치를 연결한다. 진단 작성만으로 개선 구현·배포까지 승인된 것으로 처리하지 않는다.
- IA 원본·다이어그램·검증 스크립트는 `docs/ia/`에 유지한다. 공통 점검 기록도 기존 경로를 유지하고 이 색인으로 연결한다. PRD와 디자인 시스템은 정책 원본으로 유지한다.
- 과거 보고서의 구현 설명은 작성 시점의 기록이다. 최신 코드나 운영 상태를 보장하지 않는다.
