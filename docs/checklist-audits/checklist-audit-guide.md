## 1. 제작 전 준비

[목적·사용자·범위·자료·기기·브랜드·운영 결정](../../../.claude/references/design-checklist.md#제작-전)을 확인한다. 계정·결제·외부 연동 등은 실제 기능에 해당하는 범위만 선택한다.

### 프로젝트 운영 결정

다음은 디자인 스킬로 옮기지 않는 웹사이트 제작 전 결정 사항이다. 실제 답은 프로젝트 PRD·운영 문서에 기록하고, 아래 항목을 새 기능 도입 의무로 취급하지 않는다.

| 영역 | 확인할 결정 |
| --- | --- |
| 계정·인증 | 회원 필요성·가입/로그인·세션·복구·역할·탈퇴·외부 인증 |
| 데이터·콘텐츠 | 원본·담당자·생성/수정/삭제·보존·백업·동기화·언어·외부 콘텐츠 권한 |
| 기술·외부 서비스 | 구현 환경·호스팅·연동 범위·장애 시 대안·의존성·비용·책임 주체 |
| 보안·개인정보 | 수집 목적·필요 최소 정보·동의·공개 범위·실제 접근 제어·보존/삭제 |
| 정보 구조 | 사이트 지도·메뉴·직접 링크·이전 경로 호환·찾을 수 없는 페이지 |
| SEO·외부 공유 | 검색 노출·색인·메타데이터·공유 카드·공개 범위와의 일치 |
| 분석·성과 | 측정 목적·실제 지표·이벤트·개인정보 영향·분석 실패의 서비스 영향 |
| 테스트·배포·운영 | 대상 환경·필수 검사·배포/복구·모니터링·업데이트·지원·운영 소유자 |

공통 UI 질문은 아래 스킬 문서에서 한 번만 관리한다. 전체 원문의 세부 질문이 필요하면 이 문서 끝의 백업 위치에서 확인할 수 있다.
