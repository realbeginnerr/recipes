# IA 변경 이력

현재 구조는 v1.1 YAML과 diagrams 폴더를 기준으로 읽는다. 이 문서는 변경 이유를 보존하는 보조 자료이며, 과거 제안은 현재 요구사항이 아니다.

## 제출 문서 정리 — 2026-10-19

내부 보안 설명과 외부 관리 주소를 일반화하고 상품 공개 시작 시각의 필드명을 정정했다. 남은 진입 링크 경고 2개는 운영 의도 미확인으로 표시했다. 이 정리는 IA 문서에만 적용되며 제품 코드·보안 규칙·배포 설정을 변경하지 않는다.

## 2026-10-19 — v1.1 사전 신청 기능 제거

회원가입을 제공하지 않기로 결정하여 사전 신청 화면·라우트·이메일 조회/저장·전용 스타일·분석 이벤트를 삭제했다. As-Is와 To-Be에서 해당 노드·상태·변경 제안과 전용 검증을 제거했다. 현재 As-Is 44개, To-Be 45개 노드이며 페이지는 17개다. IA-02는 기능 제거로 종결했다. 기존 신청 데이터와 실제 배포 규칙은 변경하지 않았다.

## 2026-10-18 — v1.0 분석 초판 (변경 전 기록)

아래 표와 45/46개 노드 수는 삭제 전 스냅샷이다. 사전 신청 제안과 관련 보류 항목은 v1.1에서 종료되었으며 현재 YAML에는 포함되지 않는다. 과거 ID별 상세 사유는 당시 문서 기준이며 현재 To-Be의 `changes`와 구분한다.

현재 작업 중 소스를 기준으로 As-Is를 작성하고 To-Be를 별도 제안했다. 실제 웹사이트 구현/배포 변경은 없다. YAML이 단일 원본이며 이 문서는 변경 이유를 읽기 쉽게 요약한다.

| 유형 | ID | As-Is → To-Be | 이유 / 문제 ID | 상태 |
| --- | --- | --- | --- | --- |
| Added | home-resources | 없음 → home 하위 '더 알아보기' section | 고립된 안내의 문맥 진입 / IA-01 | planned |
| Moved | roulette | site → recipes | 목록에서 선택 도구 발견 / IA-01 | planned, 페이지는 기존 구현 |
| Moved | eating-guide | site → home-resources | 홈에서 관련 정보로 소개 / IA-01 | planned, 페이지는 기존 구현 |
| Moved | signup | site → home-resources | 사전 신청 목적을 설명하고 연결 / IA-01, IA-02 | planned, IA-02 해결·운영 결정 선행 |
| Unchanged | 나머지 기존 42개 ID | 부모·이름·URL·권한 유지 | 확인된 구조를 불필요하게 재편하지 않음 | 기존 구현 유지 |

모든 기존 45개 ID를 유지했고 신규 1개로 To-Be는 46개다. 삭제·이름 변경·통합·분리·권한 변경·URL 변경은 없다. 전체 ID별 Unchanged 사유도 To-Be YAML의 `changes`에 기록한다. 부모 이동에 따른 depth/order는 파생 변경이다.

내비게이션 별도 제안: GNB `[home, recipes, ingredients]`에 기존 `shop` 진입 추가. 신규 page는 아니며 `navigation.proposal`에 planned, IA-01/IA-03 근거를 기록했다. cross_links에는 레시피 목록 → 룰렛의 planned 문맥 링크를 추가했다. IA 계층과 메뉴 목록을 구분한다.

보류 항목: signup의 운영/데이터 권한, Shop의 최종 상품 분류, 일반 사용자의 제보 진입, 상세 복귀/필터 보존. `proposals_pending`으로 관리하며 확정 신규 페이지로 만들지 않는다.

## 후속 변경 기록 양식

날짜(KST), IA 버전, 기준 코드 커밋, 관련 ID, 변경 유형, 이전/이후, 이유와 문제/요구사항 ID, 결정자/검토 상태, 구현 상태, 검증 명령/수동 확인 결과를 함께 기록한다. 구현 후에만 As-Is를 갱신한다. To-Be 승인과 실제 배포를 같은 사건으로 취급하지 않는다.
