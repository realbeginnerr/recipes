# 영어 표시 전수 점검 (2026-11-02)

## 점검 범위와 수정

- `App.tsx`에 등록된 모든 화면과 공용 컴포넌트의 표시 문구, 제목, 버튼, 입력 안내, 오류, 접근성 레이블을 소스에서 점검했다.
- 홈 영어 소개가 이전의 다른 글로 남아 있어 현재 한글 소개의 내용으로 교체했다.
- 레시피·식재료·상품·관리 화면, 외식 안내, 배송·교환·반품 안내, 금액·기간 등 동적 문구의 누락을 번역했다.
- Firestore를 **읽기만** 하여 삭제되지 않은 레시피 35개, 식재료 231개, 상품 1개, 사진 태그 상품 1개를 조사했다. 이름, 메모, 조리 과정, 조리 그룹, 플레이팅 글, 사진 상품 설명을 영어 표시 함수로 검사했으며 한글 잔존이 없었다. 삭제 기록은 복원하지 않았다.
- 영어 이름 칸에 한글이 들어간 항목과 `Radixh side dish`, `Sesame leaf`, `earl gray`, `Tomato Hall` 등 잘못되거나 불명확한 영어 표기를 바로잡았다. 번역된 이름으로 검색·정렬하도록 연결했다.

## 원문과 저장 데이터 보존

- 번역은 화면 표시 시 적용한다. 영양 정보, 수량, 사진, 문서 ID, URL, 한국어 카테고리·보관 장소·배송 업체 저장값을 변경하지 않는다.
- 조리 단계 체크는 원문과 단계 ID를 기준으로 유지하여 언어 전환 시 체크가 사라지지 않는다.
- `src/i18n/contentEnglish.ts`는 원문 문자열에 대응하는 영어 번역이다. 새 내용이나 수정된 원문에는 번역을 추가해야 한다. 원문이 바뀌면 이전 번역을 잘못 표시하지 않고 수정된 원문을 보여준다.
- 정적 문구는 `uiCopy.ts`, 검증 메시지는 `uiErrors.ts`, 보간 문구는 `uiPatterns.ts`, 홈 소개는 `about.ts`에서 관리한다.
- 데이터베이스 쓰기, 커밋, 배포는 수행하지 않았다. 최초부터 있던 문서·테스트·사진 변경은 보존했다.

## 검증 및 제한

- `tests/EnglishLocalization.test.tsx`에 홈·외식 안내·상품·정책·이름 검색·필드 오류·한영 왕복 전환·원문 저장값과 체크 상태 보존 테스트를 추가했다. `npm run test:regressions`에도 포함했다.
- 최종 `npm run test:regressions`: 9개 파일, 59개 테스트 통과. 최종 `npm run build`: TypeScript 검사 및 Vite 빌드 통과, 로컬 `dist` 갱신. 번들 크기 경고는 남아 있다.
- 외부 데이터 쓰기용 에뮬레이터 테스트를 제외한 전체 로컬 테스트: 153개 통과, 아래 기존 사진 테스트 2개 실패.
- 전체 로컬 테스트의 사진 placeholder 기대 테스트 2개는 변경 전 `ShoppableImage.tsx`로 분리 실행해도 동일하게 실패했다. 해당 동작과 테스트는 이번 번역 작업에서 변경하지 않았다.
- 실제 브라우저 확인은 Computer Use가 Windows 브라우저 URL을 신뢰성 있게 확인하지 못해 중단됐다. 컴포넌트 테스트와 빌드 성공을 실제 사용자 브라우저 검증으로 간주하지 않는다.
