## 1. 사용 방법과 상태 구분

- `확정`: 사용자가 확인한 내용. `제안`: 검토할 기획안. `확인 필요`: 자료나 결정이 없어 판매 문구로 확정할 수 없는 내용.
- 상품군 설정은 해당 종류에서 수집할 정보다. 실제 제공 조건은 개별 상품에서 확정한다.
- 판매자 고객이 사용하는 플랫폼과 이 전자책을 판매할 플랫폼을 구분한다.
- 상품의 확정 사실은 3장, 디자인·출력의 실제 값은 5·7장에서 관리한다. 제안 원고를 확정 정보처럼 재사용하지 않는다.

## 2. 상품군 공통 설정 — 전자책·디지털 자료

아래는 디지털 자료 상품에서 확인할 항목이며, 자동으로 적용되는 판매 조건이 아니다.

| 확인 항목 | 이 상품의 상태 |
| --- | --- |
| 제공 형식과 구성 | PDF 본문 + 바로 사용 가능한 MD 파일. MD에 예시 코드 포함 예정 |
| 실물 제공 여부 | 디지털 파일 상품. 실물 책이나 패키지 제공은 확인되지 않음. 실물 목업 사용 시 디지털 상품임을 명시 |
| 분량·파일 수·언어 | 확인 필요 |
| 이용 환경·필요 도구·사전 지식 | 확인 필요. 특정 AI 도구·편집기·코딩 지식이 필수라고 임의로 정하지 않음 |
| 다운로드·전달 방식·접근 기간 | 확인 필요 |
| 이용 범위 | 개인·상업 프로젝트, 고객 납품, 수정, 팀 공유 등 허용 범위 확인 필요 |
| 재배포·재판매 범위 | 확인 필요. 구매자가 자신의 제작물에 적용하는 것과 가이드 파일 자체를 배포하는 것을 구분 |
| 업데이트·지원·문의 | 제공 여부·방식 확인 필요 |
| 환불·취소·오류 파일 대응 | 판매 채널·해당 조건 확인 후 작성. 일괄 환불 불가로 임의 단정하지 않음 |
| 미리보기·샘플 | 실제 PDF·MD의 공개 가능한 범위 확인 필요 |

## 3. 개별 상품과 타깃 고객

### 3.1 확인된 상품 정보

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 상품 종류 | 전자책 | 확정 |
| 내용명 | 디자인 시스템 작성 가이드 | 사용자 표현. 최종 판매 제목은 확인 필요 |
| 적용 대상 | **상품 상세페이지 제작용 디자인 시스템** | 확정. 앞서 언급한 웹사이트 제작용 설명은 이 상품의 현재 기준으로 사용하지 않음 |
| PDF | 주된 설명 내용을 담는 본문 | 확정 |
| MD 파일 | 바로 사용 가능한 가이드, 예시 코드 포함 | 확정된 제공 계획. 실제 파일 내용·작동 환경은 검수 필요 |
| 샘플 사례 | 포함 방향으로 언급됨 | 상품군·개수·별도 파일 제공 여부 확인 필요 |
| 브랜드·저자·가격·발행일 | 미정 | 확인 필요 |

### 3.2 고객별 메시지

고객 1·2는 사용자가 제시한 구분이며, 어느 고객을 첫 화면에서 우선할지는 아직 확정하지 않았다.

| 고객 | 확인된 대상·목적 | 메시지 방향 — 제안 |
| --- | --- | --- |
| 고객 1 | 쿠팡·스마트스토어에서 제품을 판매하는 소상공인·자영업자 | 상품 상세페이지를 만들거나 제작을 의뢰할 때 사용할 기준을 정리하는 용도 |
| 고객 2 | 상세페이지 디자이너. 가이드를 통해 더 쉽고 빠르게 제작하고 업무 효율을 높이려는 사람 | 반복 제작에 활용할 디자인 기준을 문서로 만들고 적용하는 용도 |

- 두 고객을 같은 사람으로 가정하지 않는다. 직접 제작과 제작 의뢰 중 어떤 사용 방법을 실제로 지원하는지 본문 확인 후 안내한다.
- 구매 판단 질문 — 제안: 무엇을 배우고 받는가? MD를 어디에 어떻게 사용하는가? 기존 템플릿과 무엇이 다른가? 어느 수준의 지식이 필요한가? 고객 작업에 적용할 수 있는가?
- 핵심 메시지 — **제안**: “상품 상세페이지의 제작 기준을 정리하는 PDF 가이드와 바로 활용할 MD 파일.” 실제 자료 검수 후 판매 원고로 확정한다.
- “몇 분 만에 완성”, “매출 증가”, “수정 요청 감소”, “모든 상품에 최적” 등의 성과 보장은 근거 없이 사용하지 않는다.

## 4. 핵심 장점과 근거 자료

| 주장·메시지 방향 | 현재 근거·상태 | 필요한 자료 | 연결할 섹션 |
| --- | --- | --- | --- |
| 작성 방법을 PDF로 이해할 수 있음 | PDF가 메인 내용이라는 제공 계획 확인 | 실제 목차·본문 미리보기 | 제공 가치·본문 미리보기 |
| MD 가이드를 바로 활용할 수 있음 | MD와 예시 코드 제공 계획 확인 | 실제 MD 발췌, 입력·사용 과정과 결과 | 제공 구성·사용 방법 |
| 사례로 기준 적용을 살펴볼 수 있음 | 샘플 사례 언급. 상세 구성 미정 | 실제 사례와 설명, 공개 권한 | 적용 사례 |
| 반복 작업의 효율을 돕는 용도 | 고객 목적. 개선 효과를 측정한 증거는 없음 | 기준을 재사용하는 실제 과정 | 고객별 활용. 시간 단축 수치 금지 |
| 특정 플랫폼에 바로 업로드 가능한 결과물 제공 | 확인되지 않음 | 제공 범위와 실제 파일 확인 | 확정 전 주장하지 않음 |

PDF·MD 원문과 실제 사용 결과를 아직 확인하지 않았다. 이 문서 자체를 상품 효과의 근거로 사용하지 않는다. 구매자 후기·판매 실적·제작자 경력·성과 수치는 제공되지 않았으므로 만들지 않는다.

## 5. 판매 채널과 제작 방식

| 항목 | 설정 | 상태 |
| --- | --- | --- |
| 상세페이지 제작 방식 | **이미지형** | 확정 |
| 이 전자책의 판매 채널 | 미정 | 확인 필요. 고객이 쿠팡·스마트스토어 판매자라는 사실과 별개 |
| 구매·결제·파일 전달 UI | 판매 채널에 따름 | 채널 결정 후 확인. 이미지 속 가짜 구매 버튼 제작하지 않음 |
| 출력 폭·파일 형식·분할·용량 | 미정 | 채널 공식 기준 확인 후 설정 |
| 모바일 확인 크기 | 미정 | 실제 채널 표시 환경에 맞춰 설정 |
| 규격 출처·확인일 | 미기록 | 채널 결정 후 공식 문서 링크·날짜 기록 |

- 공통 문서 9장의 웹 전용 동작은 이번 제작에 적용하지 않는다.
- 이미지형 상세페이지와 판매 상품 파일을 구분한다. 상세페이지는 이미지 출력물이며, 판매 상품은 PDF·MD다.
- 긴 이미지에서 읽기 어려운 표·코드는 확대 캡처만으로 해결하지 않는다. 짧은 실제 발췌와 요점 설명으로 구성하고 전체 내용을 제공하는 파일 형식을 안내한다.

## 6. 섹션과 콘텐츠 순서

아래는 **기획 제안**이며 최종 원고·디자인은 아니다. 첫 화면의 우선 고객과 실제 자료에 따라 순서를 조정한다.

| 순서 | 섹션 | 보여줄 내용·답할 질문 | 확정 조건 |
| --- | --- | --- | --- |
| 1 | 상품 소개 | 무엇을 위한 전자책인가? PDF·MD를 제공한다는 사실과 핵심 쓰임 | 최종 제목·주 고객·대표 자료 |
| 2 | 고객별 사용 상황 | 판매자와 디자이너가 각각 어디에 활용하는가? | 실제 본문이 지원하는 사용 범위 |
| 3 | 제공 구성 | PDF와 MD 각각의 역할, 샘플·예시 코드의 포함 범위 | 실제 파일·분량 확인 |
| 4 | PDF 본문 미리보기 | 어떤 기준과 작성 방법을 배우는가? | 실제 목차·대표 페이지 |
| 5 | MD 활용 과정 | 어떤 도구에서 어떻게 사용하고 어떤 결과를 얻는가? | 지원 도구·실제 사용 사례 |
| 6 | 적용 샘플 | 실제 상품에 기준을 적용한 모습을 확인할 수 있는가? | 완성 사례·근거·공개 범위. 없으면 보류 |
| 7 | 적합한 사용자·사용 범위 | 사전 지식·필요 환경·지원하지 않는 범위 | 제공 범위 확정 |
| 8 | 구매 전 안내·FAQ | 파일 전달·이용 권한·지원·업데이트·환불 조건 | 조건 확인. 관련 제한은 앞 섹션에도 함께 표시 |
| 9 | 최종 구성·구매 안내 | 받는 파일과 확인할 조건 요약, 채널의 실제 구매 방법 | 판매 채널·가격·조건 확정 |

- 실제 후기가 없으므로 후기 섹션은 현재 계획에서 제외한다.
- 근거 없는 일반 템플릿과의 우열 비교·가상의 전후 사례는 넣지 않는다.
- 표지 목업만 반복하지 않는다. PDF·MD 실자료와 사용 예시가 구매 판단의 중심이 되게 한다.

## 7. 브랜드 스타일과 디자인 값

| 관리 항목 | 현재 설정 |
| --- | --- |
| 브랜드 분위기 | 제안: 읽기 쉽고 정돈된 실무 안내서. 최종 승인 필요 |
| 색상 | 미정. 레시피 사이트의 초록색 팔레트를 자동 상속하지 않음 |
| 글꼴 | 섹션 제목·추가 설명 모두 Pretendard 사용. 지원 언어·사용 파일의 라이선스 확인은 별도 진행 |
| 섹션 제목 | 20px · 행간 150% · Bold(700). Bold를 사용할 수 없으면 Regular(400)로 대체 |
| 추가 설명 | 16px · 행간 150% · Regular(400) |
| 그 외 글자 스타일 | 미정 |
| 제작 폭·안전 여백·정렬선 | 채널 결정 후 확정 |
| 섹션 내부·섹션 사이 간격 | 역할별 값 미정. Carbon 간격 참고 원칙 적용 |
| 라운딩·테두리·강조 방식 | 미정. 편집 콘텐츠에 웹 컨트롤 규격 강제하지 않음 |
| 실자료 표현 | 실제 PDF 페이지·MD 발췌·사용 과정을 우선. 목업은 보조 |
| 출력 형식·압축·분할 | 채널 규격 확인 후 확정 |

섹션 제목과 추가 설명의 타이포그래피는 사용자 지정값으로 확정했다. 이미지형 제작 시 원본 폭·출력 배율에 따른 모바일 실제 표시 크기를 확인한다. 그 외 미정 값은 실제 디자인 작업의 확정 토큰으로 사용하지 않는다.

## 8. 자료 목록과 추가 제작

| 자료 | 현재 보유·확인 상태 | 다음 작업 |
| --- | --- | --- |
| 상품 기획 설명·고객 정의 | 사용자 설명 확인 | 주 고객과 최종 메시지 확정 |
| 판매용 PDF | 제공 계획 확인, 실제 파일 미검토 | 목차·분량·본문·미리보기 확인 |
| 판매용 MD·예시 코드 | 제공 계획 확인, 실제 파일 미검토 | 사용 도구·예시 코드 실행 조건·재현 결과 확인 |
| 샘플 사례 | 구체 자료 미확인 | 상품군·사례 수·설명·포함 범위 확정 |
| 표지·저자·브랜드 자료 | 미제공 | 실제 자료 수집 또는 제작 |
